# DZFlood
DZFlood tool is an ArcGIS Pro Toolbox implementation of the Priority-Flood-based flow direction algorithm developed by Wu et al. (2025), offering more accurate drainage network extraction than the classic D8 method—and is fully compatible with HydroMachine Toolbox workflows. It requires a Numba-enabled clone environment.


The DZFlood tool is a flow direction estimation tool designed to be used directly within the ArcGIS Pro environment, based on an existing algorithm.

The algorithm is based on the academic paper titled “Efficient Digital Elevation Model-Based Flow Direction Estimation Using Priority Queue with Flow Distance and Zigzag Route Considerations.” However, in the original study, the algorithm was shared only as Java code, which significantly limits practical access for a broad user base.

To address this need, the algorithm has been reimplemented in the ArcGIS Pro Toolbox format, making it user-friendly and accessible.

The FlowDirection and FlowAccumulation outputs generated by the tool are directly compatible with HydroMachine Toolbox workflows. This allows you to perform your hydrological analyses with more consistent and reliable base data compared to the classic D8 method.

⚠️ A Note About Fill
The original paper states that the algorithm can work without applying a fill operation. However, I was unable to obtain consistent results using this method. Therefore, the toolbox is designed to be used exclusively with DEMs that have already had a fill operation applied. Don’t forget to apply a fill operation to your DEM before starting your analyses. Or experience the convenience of letting the built-in Fill operation handle this for you.

⚙️ Numba Setup
The Numba library was utilized to ensure the algorithm runs at a reasonable speed. Since Numba is not included in ArcGIS Pro’s default Python environment, you must first create a clone environment and install Numba there to use the toolbox. For more information on this topic, please visit Esri’s page: https://doc.esri.com/en/arcgis-pro/latest/arcpy/get-started/what-is-conda.html

Source paper for the DZFlood algorithm:
Wu, P.; Liu, J.; Xv, K.; Han, X. Efficient Digital-Elevation-Model-Based Flow Direction Estimation Using Priority Queue with Flow Distance and Zigzag Route Considerations. Water 2025, 17, 1273. https://doi.org/10.3390/w17091273
