# Privacy Policy — DZFlood Tool

DZFlood Tool collects certain system and usage information to improve performance and guide future optimizations. By downloading and using this toolbox, you agree to the data collection described below.

---

## What Data Is Collected?

| Field | Description |
|-------|-------------|
| Tool Name | Name of the tool that was executed |
| Duration (s) | How long the tool took to run (in seconds) |
| Timestamp | Date and time of execution |
| RAM (GB) | Total system memory |
| Processor | CPU model name |
| Cores / Threads | Number of CPU cores and threads |
| Windows Version | Operating system version |
| Windows Detail | Detailed OS build information |
| Python Version | Python version in use |
| ArcGIS Version | ArcGIS Pro version in use |
| Language | System language |
| Display | Screen resolution |
| Free Disk Space (GB) | Available disk space at time of execution |
| Error | Error message, if any occurred |

---

How and Where Is Data Stored?
Collected data is transmitted to a private Google Sheets spreadsheet accessible only to the developer. It is not publicly visible and is not shared with any third party.
Data is retained only for the duration of the project. All collected data will be permanently deleted upon project completion.

---

How Is This Data Used?

To understand hardware diversity across users
To identify performance bottlenecks
To prioritize future optimizations

---

What This Data Is NOT

❌ No personally identifiable information is collected
❌ No file paths, project names, or DEM content is collected
❌ Data is never sold or shared with third parties
❌ Data is not used for commercial purposes

---

Third-Party Services
Data is stored using Google Sheets, which is subject to Google's Privacy Policy. No other third-party services are involved in data transmission or storage.

Contact
If you have any questions about this policy, feel free to reach out via the GitHub repository.
